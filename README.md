# 🚶 Walkathon Challenge 2026

A responsive event microsite I designed and built for Facctum's company-wide Walkathon Challenge, an HR wellness initiative tracked on Strava.

🔗 **Live site:** https://khanammrin-coder.github.io/walkathon2026/

## About the project

The Walkathon Challenge runs for five weeks, and the daily step target goes up each week from 3.5K to 12.5K. This page is the main hub for participants. It explains the challenge, counts down to kick-off and shows the participant leaderboard.

## Features

- **Live countdown timer** to the challenge start
- **Weekly target display** with the daily step minimum and challenge window
- **Participant list and leaderboard** loaded dynamically, updated weekly by HR
- **Step-by-step Strava guide** for logging walks correctly
- **Scoring explainer** showing how extra steps add to your rank
- **Rules & FAQs** section covering common participant questions
- **Downloadable poster** for sharing on Teams and email
- Fully **responsive**, so it works on mobile and desktop

## Built with

- HTML5
- CSS3
- JavaScript

## What I learned

Building this taught me how to turn HR program rules into a clear, engaging page that employees would actually read, and how to keep content up to date week by week.
